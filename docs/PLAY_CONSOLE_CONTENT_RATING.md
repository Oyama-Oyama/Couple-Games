# Google Play 内容分级与敏感内容政策复核（v2.1.0）

> 本文件供上架前在 Play Console 填写「内容分级问卷」与「敏感内容政策声明」时逐项核对。
> 应用定位：情侣双人私密互动桌游（20 个模式），含含蓄亲密提示卡、二选一问答、角色扮演，含订阅付费。

---

## 1. 内容分级问卷（Content Rating Questionnaire）建议答复

Google Play 采用 IARC 问卷。以下为基于实际题库内容的建议答案（请复核后提交）：

| 问题项 | 建议回答 | 依据 |
|---|---|---|
| 暴力/恐怖 (Violence & Horror) | 无 / None | 题库无任何暴力、血腥、恐怖内容 |
| 粗俗语言 (Strong Language) | 偶尔温和 / Mild, infrequent | 无脏话；有 "naughty"、"bold" 等温和措辞 |
| 裸露内容 (Nudity) | 无图形裸露 / No graphic nudity | 文本提及 "underwear"、"slip off a layer"，无任何图像裸露 |
| 性暗示内容 (Sexual Themes) | **有 — 暗示性/含蓄** (Suggestive / Mild) | 题库含亲密触碰、亲吻、身体部位指向等文字描述；**无露骨性行为描写** |
| 成人主题/粗俗幽默 | 温和 | 情侣间害羞探索语境，非粗俗 |
| 酒精/烟草/药物 | 轻微提及 | 题库有 "tipsy"、"clink glasses" 等微醺情境文字，无真实物品展示或鼓励 |
| 赌博 (Gambling) | 无真实赌博 | 游戏内筹码/竞拍为虚拟积分，不可兑换现金 |
| 在线互动 | 无 | 应用纯离线双人本地互动，无联网、无陌生人社交 |
| 用户生成内容 | 有限（自定义卡牌/扇区） | 有本地自定义卡输入，无发布/分享功能 |

**建议分级结果**：**Mature 17+**（因含性暗示主题 + 付费订阅）；保守起见也可申报 **Adults 18+**。

> ⚠️ 若在问卷中对「性暗示内容」勾选高于 Suggestive，Google 可能要求 18+ 并限制部分国家曝光。请如实申报。

## 2. 敏感内容政策复核（Sensitive Content Policy）

### 2.1 性与生殖内容政策（Sexual Content）
Google Play 禁止的是**露骨色情内容（explicit sexual content）**，包括：
- 明确的性行为描写/图像 — ✅ 本应用**无**（题库为含蓄文字提示，止于亲吻/触碰/暗示）
- 色情图片/视频 — ✅ **无**（应用无图片类题目，纯文字卡）
- 性玩具/露骨器物 — ✅ **无**

本应用内容尺度：情侣间的亲吻、拥抱、轻触、害羞告白、角色扮演情境。**属于政策允许的"成年人亲密关系"范畴**，但必须在内容分级中如实勾选性暗示主题。

### 2.2 付费订阅政策（Subscriptions）
- 订阅商品：`velvet_weekly_pass`（周）、`velvet_annual_pass`（年），一次性买断 `velvet_lifetime_unlock`。
- 必须在应用内清晰展示：价格、自动续订条款、取消方式、隐私政策链接、服务条款链接。
- Google Play 要求订阅需在应用内有明确的「管理订阅」入口。
- 自动续订必须提前告知，且可随时取消。

### 2.3 隐私政策与数据安全（Data Safety）
- 应用纯离线运行，无账号系统、无云同步、无分析 SDK、无广告 SDK。
- **必须提供可访问的隐私政策 URL**（Play Console Data Safety 表单必填）。
- Data Safety 表单建议：无数据收集、无数据共享（如实际为 0，请如实勾选）。

### 2.4 家庭政策 / 儿童安全（Families Policy）
- 应用**不属于**面向儿童的应用（Family bookmark）。
- 首次启动应有年龄确认或明确的成人向定位说明，避免被归入儿童目录。
